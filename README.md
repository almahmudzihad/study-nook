# StudyNook

StudyNook is a modern study room booking platform where users can browse, book, manage, and list study rooms easily. It provides a seamless experience for students and library users to find the perfect study environment.

## 🌐 Live Website

Live Site: https://study-nook-alpha.vercel.app

## 🚀 Features

- 🔐 Secure authentication system using Better Auth (Email/Password & Google Login)
- 📚 Browse and search available study rooms
- 🏠 Add, edit, and delete personal room listings
- 📅 Book study rooms with date and time selection
- 📌 Manage bookings with booking cancellation support
- 👤 Personalized dashboard for managing listings and bookings
- ⚡ Responsive and modern UI for mobile, tablet, and desktop

## 🛠️ Tech Stack

### Client Side
- Next.js
- React.js
- Tailwind CSS
- Better Auth
- React Toastify
- React Spinners

### Server Side
- Node.js
- Express.js
- MongoDB

## 📦 Dependencies

```bash
npm install
```

## ▶️ Run Locally

Clone the project

```bash
git clone https://github.com/almahmudzihad/study-nook.git
```

Go to the project directory

```bash
cd study-nook
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
